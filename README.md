# L++ (L加加)

![L++ Logo](lpp.png)
*(如果你是第一次看到这个项目，请确保 lpp.png 图片与 README 在同一个目录下)*

**L++ (L加加) 是一门基于 C++ 内核开发的中文编程语言。**
它旨在打破编程语言的英语壁垒，让中文母语者能够用最自然、最直观的语法进行逻辑表达与开发。

---

## ✨ 核心特性

*   **📖 纯中文语法**：使用 `设`、`打印`、`如果那么`、`否则`、`重复执行` 等中文关键字，编程像写文章一样自然。
*   **🧠 持久化记忆**：自带 `lpp.mem` 记忆文件，程序关闭后变量不会丢失，下次打开继续用！
*   **⚡ C++ 内核**：底层由 C++ 编写，执行效率高，结构稳定可靠。
*   **📦 开箱即用**：提供 Windows 便携版，无需配置任何运行环境，解压双击就能跑。
*   **🔗 嵌套逻辑**：支持复杂的条件判断与循环嵌套，足以应对绝大多数日常逻辑编写。

---

## 🚀 快速开始 (Windows 用户)

**不用懂 C++，不用装编译器，直接玩！**

1. 点击本仓库右侧的 **[Releases](https://github.com/lixytag/Lpp/releases)** 页面。
2. 下载最新版本的 `.zip` 压缩包（包含便携版 exe）。
3. 解压到任意文件夹。
4. 双击解压出来的 `.exe` 文件，即可启动 L++ 交互界面。

*(在 L++ 的提示符 `L++ >` 后面输入代码，按回车执行)*

## 📖 基础语法示例

在 L++ 的交互界面中，你可以直接输入以下命令并回车：

### 1. 打印输出
使用 `打印` 关键字输出文字或变量内容。
```lpp
打印 "元宵节大烧甜66666"
2. 变量定义与赋值
使用 设 关键字定义变量，支持基本数据类型。

lpp
设 a = 10
设 b = 20
设 姓名 = "李华"
3. 数学运算
支持标准加减乘除，甚至可以直接在交互界面当计算器用。

lpp
1 + 1
a * b
4. 条件判断（如果...那么...否则）
支持基于条件的逻辑分支。

lpp
如果 a > 5 那么
    打印 "a 大于 5"
否则
    打印 "a 不大于 5"
5. 循环执行（重复执行）
用于重复执行某段代码。

lpp
设 i = 0
重复执行 5 次
    打印 i
    设 i = i + 1
6. 记忆管理
由于 L++ 自带持久化记忆，你甚至不需要重启程序。

lpp
清空记忆  // 清空当前保存的所有变量记忆
exit      // 退出 L++ 交互界面
🛠️ 从源码编译 (开发者)
如果你熟悉 C++，想要自己从源码编译 L++，请确保你的电脑安装了 g++ (MinGW)。
在源码目录下执行以下命令（将 你的源码文件名.cpp 替换为实际的源码文件）：

1. 编译资源文件 (生成图标)：

bash
windres icon.rc -O coff -o icon.res
2. 编译主程序 (包含静态链接和图标)：

bash
g++ "你的源码文件名.cpp" "icon.res" -o "你的输出程序名.exe" -static -mconsole
(注意：-static 保证静态链接，-mconsole 强制生成控制台程序入口)
