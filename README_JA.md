L++ (L加加)

1. 出力（プリント）
打印 キーワードを使用して、テキストや変数の内容を出力します。

🛠️ ソースコードからのコンパイル（開発者向け）
C++ に精通しており、ご自身で L++ をソースコードからコンパイルしたい場合は、お使いの PC に g++(MinGW) がインストールされていることを確認してください。
